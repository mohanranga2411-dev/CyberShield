# 🛡 CyberShield AI

An Intelligent Phishing Threat Detection and URL Risk Assessment Platform built using Python Flask.

## Features

- URL Risk Analysis
- Phishing Detection
- HTTPS Validation
- IP Address Detection
- Suspicious Keyword Detection
- Risk Scoring System
- Futuristic Cybersecurity UI

## Tech Stack

- Python
- Flask
- HTML
- CSS
- Bootstrap

## Installation

```bash
pip install flask
python app.py
```
